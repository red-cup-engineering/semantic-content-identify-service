# Semantic Content Identify Service

A public one-operation service and Capability Cell candidate: derive canonical
RMN CBOR bytes and an RFC 6920 SHA-256 `ni` URI from one semantic value.

```sh
printf '["star"]' | semantic-content-identity
```
